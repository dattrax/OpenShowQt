# M6 async integration follow-up verification

Implementation follow-up to the [post-6.22 review](M6-post-6.22-review-2026-10-31.md).
Historical findings remain unchanged; this document records their closure evidence.

## 6.23a — Standalone retirement reservation

A completed stage makes one supersession decision under the intent lock and
reserves the bounded retirement slot before surrendering ownership. Both live
replacement and superseded-stage retirement use the same checked reservation;
a busy slot retains the held stage and never overwrites a joinable lane.

`testStandaloneClaimReservesRetirement` injects C from a request thread as staged
B becomes claimable while A has a scripted 1500 ms stop. It verifies preserved
retirement ownership, silent B, responsive passes, eventual C and clean shutdown.
`ctest --preset desktop -R '^background_transport_tests$'`: **1/1 PASS, 9.22 s**
with local PipeWire and Vulkan access; the new live-audio case executed.

## 6.23b — Deferred output transaction

Background application returns applied, video-started, deferred or failed; the
transport no longer retries a media-only transition. OutputSession retains the
scene and retries after retirement capacity returns, suppressing redundant
command-only frames while continuing the current video. A transaction backup
keeps the old background status until the same successful present publishes the
new scene; standalone status remains independent. Named media failures retain
the existing explicit colour-fill fallback.

`async_integration_tests` drives the production WorkerController, worker and
PreviewConsumer. A→B→C and A→B→clear hold B's active scene, global revision,
media path and green pixels while the new scene remains pending; B continues
presenting. Eventual replacement/clear and cancellation back to B are verified.
The transport capacity fixtures now retry from their caller, matching ownership.

The new integration fixture passed in 16.34 s; transport passed in 8.98 s and
output status passed in the same targeted run. WorkerController's existing
suite also passed (54.29 s) during this fix. All used local-session access.

6.23c–e remain open. No full-suite claim is made for this intermediate change.
