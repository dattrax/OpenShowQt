## 6.23a — Standalone retirement reservation

A completed stage makes one supersession decision under the intent lock and
reserves the bounded retirement slot before surrendering ownership. Both live
replacement and superseded-stage retirement use the same checked reservation;
a busy slot retains the held stage and never overwrites a joinable lane.

`testStandaloneClaimReservesRetirement` injects C from a request thread as staged
B becomes claimable while A has a scripted 1500 ms stop. It verifies preserved
retirement ownership, silent B, responsive passes, eventual C and clean shutdown.
`ctest --preset desktop -R '^background_transport_tests$'`: **1/1 PASS, 9.22 s**
with local PipeWire and Vulkan access; the new live-audio case executed.
